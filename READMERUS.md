# 📄 116FZ-Doc-Generator

### Система автоматизации подготовки документов по 116-ФЗ

Веб-приложение для управления данными об опасных производственных объектах (ОПО) и автоматической генерации документации.

---

## 🚀 Технологический стек

- **Backend:** Java 21, Hibernate 6 (ORM)
- **Database:** PostgreSQL 18
- **Web Server:** Apache Tomcat 10.1
- **Infrastructure:** Docker, Docker Compose, Maven
- **Deployment:** Railway Cloud

---

## 🛠️ Функционал

- Управление объектами (ОПО)
- Ведение справочников:
  - АСФ (аварийно-спасательные формирования)
  - Опасные вещества
  - Организации
- Автоматическая генерация документов (Word)
- Работа с шаблонами и подстановкой данных
- Интеграция с БД через Hibernate
- Поддержка cloud-деплоя через переменные окружения

---

## 📄 Генерация документов

Система автоматически формирует документы на основе шаблонов с использованием:

- pipeline-обработки
- стратегий подстановки плейсхолдеров
- фабрик блоков (таблицы, списки, изображения)

---

## 🧠 Архитектура

Приложение построено по слоистой архитектуре:

- **web** — сервлеты (контроллеры)
- **app** — bootstrap и DI-контекст
- **domain**
  - model — сущности
  - repository — интерфейсы
  - service — бизнес-логика
- **infrastructure** — реализация через Hibernate

Реализован собственный lightweight DI:

- `RepositoryContext`
- `InternalServices`
- `Bootstrap`

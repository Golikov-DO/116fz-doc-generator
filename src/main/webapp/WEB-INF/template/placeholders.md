## Простой текст

- `${ASF_ARRIVAL_TIME}` — Время прибытия АСФ до объекта в ч : мин
- `${ASF_AVAILABLE_SPECIALISTS}` — Количество специалистов АСФ для проведения работ
- `${ASF_CONTACT_NUMBER}` — Номер телефона АСФ для сообщения о ЧС
- `${ASF_FULL_NAME_GEN}` — Полное название АСФ в родительном падеже
- `${ASF_FULL_NAME}` — Полное название АСФ
- `${ASF_SHORT_NAME}` — Сокращённое название АСФ
- `${ASF_SIGNER_NAME}` — Фамилия и инициалы подписанта от АСФ
- `${ASF_SIGNER_POSITION}` — Должность подписанта от АСФ
- `${ASF_STATUS_SHORT}` — Сокращённое название статуса АСФ
- `${ASF_STATUS}` — Полное название статуса АСФ
- `${ASF_WORK_TYPES}` — Вид работ АСФ
- `${ASF_AREA_RESPONSIBILITY}` — Зона ответственности АСФ
- `${ASF_PLACE_LOCATION}` — Место дислокации АСФ
- `${ASF_DUTY_OFFICER_PHONE}` — Номер телефона оперативного дежурного АСФ
- `${ASF_RECEPTION_PHONE}` — Номер телефона приёмной АСФ
- `${ASF_E_MAIL}` — Электронный адрес АСФ
- `${ASF_NUMBER_BUILDINGS}` — Количество зданий(сооружений) АСФ
- `${ASF_TOTAL_BUILDING_AREA}` — Общая площадь зданий(сооружений) АСФ в м² в собственности или аренде
- `${ASF_CERTIFIED_RESCUERS}` — Перечень аттестованных спасателй АСФ по классности
- `${ASF_NUMBER_PERSONNEL_STAFF}` — Количество личного состава АСФ по штату
- `${ASF_NUMBER_PERSONNEL_LIST}` — Количество личного состава АСФ по списку

- `${OBJ_ADDRESS_FULL}` — Полный адрес объекта
- `${OBJ_AMOUNT_HAZARDOUS_SUBSTANCE}` — Количество опасного вещества на объекте
- `${OBJ_AMOUNT_TECHNOLOGICAL_BLOCK}` — Количество технологических блоков на объекте
- `${OBJ_AREA_LOCATION}` — Характеристика района расположения объекта
- `${OBJ_DEPARTMENT_GOCHS_CITY}` — Управления по делам ГО и ЧС города (села) по месту нахождения объекта
- `${OBJ_EMERGENCY_COMMISSION}` — Создана или нет КЧС и ОПБ на объекте
- `${OBJ_HAZARDOUS_SUBSTANCE_GEN}` — Используемое опасное вещество в родительном падеже на объекте
- `${OBJ_HAZARDOUS_SUBSTANCE}` — Используемое опасное вещество на объекте
- `${OBJ_HAZARD_CLASS}` — Класс опасности объекта
- `${OBJ_INSURANCE_POLICY_DATE}` — Дата страхового полиса для объекта
- `${OBJ_INSURANCE_POLICY_NUMBER}` — Номер страхового полиса для объекта
- `${OBJ_NAME}` — Полное название объекта
- `${OBJ_NEAREST_FIRE_STATION}` — Ближайшая ПСЧ(СЧ) к объекту
- `${OBJ_ORDER_MINIMUM_BALANCE_DATE}` — Дата приказа о наличии неснижаемого остатка денежных средств на объекте
- `${OBJ_ORDER_MINIMUM_BALANCE_NUMBER}` — Номер приказа о наличии неснижаемого остатка денежных средств на объекте
- `${OBJ_TYPE_DIFINITION}` — Определение типа объекта по ГОСТУ

- `${ORG_ADDRESS_FULL}` — Полный адрес организации
- `${ORG_NAME}` — Полное название организации
- `${ORG_SHORT_NAME}` — Сокращённое название организации
- `${ORG_SIGNER_NAME}` — Фамилия и инициалы подписанта от организации
- `${ORG_SIGNER_POSITION}` — Должность подписанта от организации
- `${ORG_TYPE_ACTIVITY}` — Основной вид деятельности организации с маленькой буквы

## Таблицы

- `${OBJ_LINC_TEXT_X_TABLE}` — Текстовая ссылка в документе на таблицу под номером Х
- `${OBJ_NUM_X_TABLE"}` — Номер Х таблиц в документе
- `OBJ_TABLE_X_PLACEHOLDER` — Место заполнения таблиц с номером Х
- `${OBJ_TEXT_NAME_X_TABLE}` — Текстовое имя таблиц с номером Х

## Списки 

- `OBJ_STRUCTURE_LIST` — Список состава объекта в виде: 1.) ... 2.) ...
- `OBJ_TECHNO_BLOCK_LIST` — Список блоков объекта в виде № 1 ... № 2 ...
- `OBJ_SCENARIO_LIKELY_LIST` — Список наиболее вероятных сценариев
- `OBJ_SCENARIO_DANGEROUS_LIST` — Список наиболее опасных по последствиям ЧС сценариев

## Картинки

- `${OBJ_LINC_TEXT_Х_IMAGE}` — Текстовая ссылка в документе на картинку с номером Х
- `${OBJ_NUM_Х_IMAGE"}` — Номер Х картинки в документе
- `OBJ_IMAGE_Х_PLACEHOLDER` — Место картинки с номером Х
- `${OBJ_TEXT_CAPTURE_Х_IMAGE}` — Текстовая подпись картинки с номером Х
- `ASF_IMAGE_1_APPENDIX` — Скан свидетельства может быть несколько картинок приложение 1
- `ASF_IMAGE_2_APPENDIX` — Скан паспорта ПАСФ может быть несколько картинок приложение 2

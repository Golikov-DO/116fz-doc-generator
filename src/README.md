# 📄 116FZ-Doc-Generator

### Система автоматизации подготовки документов по 116-ФЗ
Сервис для управления объектами, организациями и автоматической генерации документации.

---

## 🚀 Технологический стек
*   **Backend:** Java 21, Hibernate 6 (ORM)
*   **Database:** PostgreSQL 18
*   **Web Server:** Apache Tomcat 10.1
*   **Infrastructure:** Docker, Docker Compose, Maven
*   **Deployment:** Railway Cloud

---

## 🛠️ Функционал
*   **Управление объектами:** Редактирование данных об опасных производственных объектах (ОПО).
*   **Справочники:** Ведение баз данных по АСФ (аварийно-спасательным формированиям), опасным веществам и организациям.
*   **Интеграция с БД:** Автоматическое создание/валидация таблиц через Hibernate.
*   **Cloud Ready:** Конфигурация через переменные окружения для легкого деплоя.

---
